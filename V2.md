# Dashboard V2

V2 ialah dashboard utama dan membaca jadual agregat sahaja:

- `dashboard_aging_runs_v2`
- `dashboard_aging_aggregates_v2`
- `dashboard_application_daily_aggregates_v2`
- `dashboard_pending_validation_aggregates_v2`
- `dashboard_officer_daily_aggregates_v2`

Jumlah permohonan belum diperaku dikira daripada jumlah `application_count`. Nama pemohon, nombor pengenalan pemohon, nombor telefon, dan nombor rujukan tidak dibaca atau disimpan dalam jadual V2.

Akses dashboard dihadkan melalui Supabase Auth, allowlist, dan RLS.
